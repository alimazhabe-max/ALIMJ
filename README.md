## ⚙️ نصب و اجرا

### ۱. نصب پکیج‌ها

```bash
pip install -r requirements.txt
```

### ۲. متغیرهای محیطی

فایل `.env` بساز:

```env
BOT_TOKEN=123456:ABC-your-token
ADMIN_IDS=123456789
CHANNEL_ID=@yourchannel
CHANNEL_LINK=https://t.me/yourchannel
TIMEZONE=Asia/Tehran
RATE_LIMIT=60
START_RATE_LIMIT=10
```

| متغیر | توضیح | پیش‌فرض |
|:------|:------|:-------:|
| `BOT_TOKEN` | توکن از [@BotFather](https://t.me/BotFather) | — |
| `ADMIN_IDS` | آیدی عددی ادمین‌ها (با ویرگول) | — |
| `CHANNEL_ID` | کانال عضویت اجباری | — |
| `CHANNEL_LINK` | لینک کانال | — |
| `TIMEZONE` | منطقه زمانی | `Asia/Tehran` |
| `RATE_LIMIT` | سقف پیام در دقیقه | `60` |
| `START_RATE_LIMIT` | سقف `/start` در دقیقه | `10` |

### ۳. اجرا

```bash
python -m bot.main
```
